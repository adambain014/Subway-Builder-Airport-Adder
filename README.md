# Subway-Builder-Airport-Adder
Add new airport terminals to subway builder! Also useful for intercity rail stations and border crossings
# Installation
Download r and rstudio (https://posit.co/download/rstudio-desktop/)

Download the .rmd

Copy it into the folder that has the city you wish to edit. (On Windows it should be something like C:\Users\Sam\AppData\Local\Programs\Subway Builder\resources\data\[CITY CODE])

# Usage
Run the script, changing values in the 4th block to suit needs
